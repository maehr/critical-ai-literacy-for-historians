# Glossary Creation Skill

This skill outlines the standard for adding and maintaining glossary terms.

## 1. Glossary Location

- **Primary File**: `glossary.qmd` (assumed location: root or language specific folder, e.g., `en/glossary.qmd`, `de/glossary.qmd`, `fr/glossary.qmd`).
- Check if a central glossary data file exists (e.g., `_data/glossary.yml`). If not, maintain separate `qmd` files for now.

## 2. Term Structure

When defining a term:

1. **Term Name**: Bold or Heading level appropriate for the list.
2. **Definition**: Clear, concise definition relevant to AI and History.
3. **Context**: How it applies to historical research or source criticism.
4. **See Also**: Links to related terms.

## 3. Multilingual Consistency

- Ensure terms are translated across all three languages.
- Keep definitions conceptually equivalent, even if wording differs slightly for cultural context.
